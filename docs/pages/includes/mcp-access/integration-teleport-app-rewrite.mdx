You can register an MCP application in Teleport by defining it in your Teleport
Application Service configuration, or by using dynamic registration with `tctl`
or Terraform:

<Tabs>
<TabItem label="Static configuration">
Replace <Var name="MCP_HOST"/> with the host running the {props.serviceName} MCP server:
<CodeBlock>
{
 `app_service:
    enabled: "yes"
    apps:
    - name: "${ props.service }-mcp"
      uri: "mcp+http://<Var name="MCP_HOST"/>:${ props.port }/mcp"
      labels:
        env: dev
        service: ${ props.service }
      rewrite:
        headers:
        - "${ props.headerName }: ${ props.headerValue }"`
}
</CodeBlock>

Restart the Application Service.
</TabItem>

<TabItem label="tctl">
Create an `app` resource definition file named `app-{props.service}-mcp.yaml`. Replace
<Var name="MCP_HOST" /> with the host running the {props.serviceName} MCP server:
<CodeBlock>
{
 `# app-${ props.service }-mcp.yaml
  kind: app
  version: v3
  metadata:
    name: ${ props.service }-mcp
    labels:
      env: dev
      service: ${ props.service }
  spec:
    uri: "mcp+http://<Var name="MCP_HOST" />:${ props.port }/mcp"
    rewrite:
      headers:
      - name: "${ props.headerName }"
        value: "${ props.headerValue }"`
}
</CodeBlock>

Create the `app` resource with:
<CodeBlock>
{
 `$ tctl create -f app-${ props.service }-mcp.yaml`
}
</CodeBlock>
</TabItem>

<TabItem label="Terraform">
Create a `teleport_app` resource in terraform. Replace <Var name="MCP_HOST" />
with the host running the {props.serviceName} MCP server:
<CodeBlock>
{
 `resource "teleport_app" "grafana" {
    version = "v3"
    metadata = {
      name = "${ props.service }-mcp"
      labels = {
        "teleport.dev/origin" = "dynamic"
        "env"                 = "dev"
        "service"             = "${ props.service }"
      }
    }
  
    spec = {
      uri = "mcp+http://<Var name="MCP_HOST" />:${ props.port }/mcp"
      rewrite = {
        headers = [{
          name  = "${ props.headerName }"
          value = "${ props.headerValue }"
        }]
      }
    }
  }`
}
</CodeBlock>
Apply the configuration:
```code
$ terraform apply
```
</TabItem>

</Tabs>
