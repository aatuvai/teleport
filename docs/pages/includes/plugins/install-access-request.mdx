<TabItem label="Download">

Access Request Plugins are available as `amd64` and `arm64` Linux binaries for downloading.
Replace `ARCH` with your required version.

<CodeBlock>
{
 `$ curl -L -O https://cdn.teleport.dev/teleport-access-${ props.name }-v(=teleport.plugin.version=)-linux-<Var name="ARCH" />-bin.tar.gz
  $ tar -xzf teleport-access-${ props.name }-v(=teleport.plugin.version=)-linux-<Var name="ARCH" />-bin.tar.gz
  $ cd teleport-access-${ props.name }
  $ sudo ./install`
}
</CodeBlock>

Make sure the binary is installed:

<CodeBlock>
{
 `$ teleport-${ props.name } version
  teleport-${ props.name } v(=teleport.plugin.version=) git:teleport-${ props.name }-v(=teleport.plugin.version=)-fffffffff go(=teleport.golang=)`
}
</CodeBlock>

</TabItem>
<TabItem label="Docker Image">

<CodeBlock>
{
 `$ docker pull public.ecr.aws/gravitational/teleport-plugin-${ props.name }:(=teleport.plugin.version=)`
}
</CodeBlock>

Make sure the plugin is installed by running the following command:

<CodeBlock>
{
 `$ docker run public.ecr.aws/gravitational/teleport-plugin-${ props.name }:(=teleport.plugin.version=) version
  teleport-${ props.name } v(=teleport.plugin.version=) (=teleport.golang=)`
}
</CodeBlock>

For a list of available tags, visit [Amazon ECR Public Gallery](https://gallery.ecr.aws/gravitational/teleport-plugin-{props.name}).

</TabItem>
<TabItem label="From Source">
To install from source you need `git` and `go` installed. If you do not have Go
installed, visit the Go [downloads page](https://go.dev/dl/).

<CodeBlock>
{
 `$ git clone https://github.com/gravitational/teleport -b branch/v(=teleport.major_version=)
  $ cd teleport/integrations/access/${ props.name }
  $ git checkout v(=teleport.plugin.version=)
  $ make build/teleport-${ props.name }`
}
</CodeBlock>

Move the `teleport-{props.name}` binary into your PATH.

Make sure the binary is installed:

<CodeBlock>
{
 `$ teleport-${ props.name } version
  teleport-${ props.name } v(=teleport.plugin.version=) git:teleport-${ props.name }-v(=teleport.plugin.version=)-fffffffff go(=teleport.golang=)`
}
</CodeBlock>

</TabItem>
