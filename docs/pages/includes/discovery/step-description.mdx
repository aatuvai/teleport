Teleport {props.resourceDesc} auto-discovery involves two components:

1. The Teleport Discovery Service that watches for new {props.resourceDesc}s or
changes to previously discovered {props.resourceDesc}s.
It dynamically registers each discovered {props.resourceDesc} as a
`{props.resourceKind}` resource in your Teleport cluster.
It does not need connectivity to the {props.resourceDesc}s it discovers.
2. The Teleport {props.serviceName} Service that monitors the dynamic
`{props.resourceKind}` resources registered by the Discovery Service.
It proxies communications between users and the {props.resourceDesc}.
