Assign <Var name="aws-account-id"/> to your AWS account ID:

<CodeBlock>
{
 `{
      "Version": "2012-10-17",
      "Statement": [
          {
              "Sid": "KeyspacesConnectAsIAMRole",
              "Effect": "Allow",
              "Action": "sts:AssumeRole",
              "Resource": [
                  "arn:aws:iam::<Var name="aws-account-id"/>:role/${ props.dbUserRole }"
              ]
          }
      ]
  }`
}
</CodeBlock>

| Statement | Purpose |
| --------- | ------- |
|`KeyspacesConnectAsIAMRole`| Assume an IAM role to forward requests to Keyspaces. |
