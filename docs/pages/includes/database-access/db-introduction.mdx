Teleport can provide secure access to {props.dbType} via the  [Teleport Database
Service](../../enroll-resources/database-access/database-access.mdx). This allows for
fine-grained access control through [Teleport's RBAC](../../enroll-resources/database-access/rbac.mdx).

In this guide, you will:

1. Configure your {props.dbType} database {props.dbConfigure}.
1. Add the database to your Teleport cluster.
1. Connect to the database via Teleport.
