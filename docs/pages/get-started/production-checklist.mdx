## Step-by-Step Production Setup Guide

A step-by-step checklist to guide you through Teleport production setup, with video walkthroughs and timestamp links to help you quickly find the relevant steps.

    <ChecklistItem timestamp={60}>Manage Teleport configuration changes through review and CI: for Terraform, use plan/apply in CI (e.g., [Spacelift](../configuration/terraform-provider/spacelift.mdx), [Terraform Cloud](../configuration/terraform-provider/terraform-cloud.mdx)), which Teleport documents explicitly as a GitOps-style workflow with PR review and an audit trail; for the [Kubernetes Operator](../configuration/teleport-operator/teleport-operator.mdx), apply CRs through a reviewed, version-controlled pipeline rather than ad hoc `kubectl apply`.</ChecklistItem>
    <ChecklistItem timestamp={120}>Secure IaC credentials and sensitive configuration data: prefer [delegated join methods](../configuration/terraform-provider/ci-or-cloud.mdx) over [long-lived credentials](../configuration/terraform-provider/long-lived-credentials.mdx) for Terraform; confirm [Kubernetes-native joining and RBAC scope](../configuration/teleport-operator/teleport-operator-standalone.mdx) for the Operator; and use a non-local, encrypted Terraform backend so state persists across CI/CD runs and doesn't expose sensitive values; prefer [ephemeral resources](../reference/machine-workload-identity/terraform-provider-mwi/terraform-provider-mwi.mdx) for MWI where supported</ChecklistItem>
