## Auth Connection Config

Defines the parameters used to connect to the Auth Service.


Example:

```yaml
upper_limit_between_retries: # See description
initial_connection_delay: # See description
backoff_step_duration: # See description
```

|Field Name|Description|Type|
|---|---|---|
|backoff_step_duration|The amount of time added to the retry delay.||
|initial_connection_delay|The initial delay before the first retry attempt. The retry logic will apply jitter to this duration.||
|upper_limit_between_retries|The upper limit for how long to wait between retries.||

## Bound Keypair Params

Contains parameters specific to bound keypair joining.


Example:

```yaml
registration_secret_value: "string"
registration_secret_path: "string"
static_key_path: "string"
```

|Field Name|Description|Type|
|---|---|---|
|registration_secret_path|A path to a file on the local disk containing a registration secret. It is incompatible with RegistrationSecretValue.|string|
|registration_secret_value|An explicit registration secret value, used to authenticate the initial join with a bound keypair token. It becomes inert once used.|string|
|static_key_path|A path to a file on the local disk containing a static keypair to be used for bound keypair joining. Static keys are immutable and are not managed automatically. They must be preregistered, do not support automatic keypair rotation, and must be used with a token set to use `insecure` recovery mode.|string|

## Log

Configures teleport logging


Example:

```yaml

severity: "string"
format: # [...]
```

|Field Name|Description|Type|
|---|---|---|
|format|Defines the logs output format and extra fields|[Log Format](#log-format)|
|output|Defines where logs go. It can be one of the following: "stderr", "stdout" or a path to a log file|string|
|severity|Defines how verbose the log will be. Possible values are "error", "info", "warn"|string|

|Field Name|Description|Type|

## Params

Type defines a flexible unified back-end configuration API. It is just a map of key/value pairs which gets populated by `storage` section in Teleport YAML config.


## Strings

A list of string that can unmarshal from list of strings or a scalar string from scalar yaml or json property
